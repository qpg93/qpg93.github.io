Emma，这篇写给你，也写给以后会读到这里的 Yoyo。

最早，我们问的还是“那个结构到底是什么”“要不要现在住院”。后来，问题慢慢变成了“看到胎心了吗”“NT 是什么”“这次又长大了多少”。一份份报告连起来，才看得见这段孕期走过的路。

Yoyo 的变化藏在那些越来越具体的测量里，Emma 的变化则发生在自己的身体上。这里会把两个人都写下来。也希望关心我们的朋友，不必先学会读一整张检查单，就能跟着看懂。

| 术语 | 用日常的话理解 |
| --- | --- |
| 宫内妊娠／异位妊娠 | 分别指妊娠着床在子宫腔内，或在子宫腔以外。复合妊娠指两者同时存在，不能由“有一个可疑包块”直接确认。 |
| 子宫肌层／宫角 | 肌层是子宫壁的肌肉部分；宫角指子宫上部两侧、与输卵管相邻的区域，是位置描述。 |
| 低回声／无回声 | 超声图像里相对较暗、或没有明显回声的区域。这些词描述图像，不等于某一种疾病；无回声区也不能直接叫“另一个孕囊”。 |
| 子宫肌瘤 | 子宫内或周围的常见非癌性增生。本文仍保留报告中的“可能”和“变性可能”，不把所有结节都当作已经确诊的肌瘤。 |
| HCG（hCG） | 人绒毛膜促性腺激素，妊娠相关的一种激素，可通过血液或尿液检测。它不是胎儿大小或健康程度的分数。 |
| 孕酮／雌二醇（E2） | 两种与妊娠有关的激素；E2 是雌二醇的缩写。单次结果不能替代整体产检评估。 |
| CRL／原始心管搏动 | CRL 是头臀长，即头顶部到臀部的距离，不是全身长度；原始心管搏动是早期超声记录心脏搏动的用语。 |
| NT | 颈后透明层，早孕超声中的一个测量项目，用于筛查评估的一部分。下文配有位置简图。 |
| NIPT／三体低风险 | NIPT 是无创产前筛查，分析孕妇血液中的游离 DNA，评估部分染色体数目异常的风险。“三体”指相应染色体多了一份；低风险不等于诊断正常或零风险。 |
| PI／RI | 根据多普勒超声血流波形计算的搏动指数和阻力指数，用于描述血流特征；不是血压读数。 |
| BPD／HC／AC／FL | 分别是双顶径、头围、腹围、股骨长。前两项看头部，AC 看腹部，FL 测股骨，不是四种互相可替代的身长。 |
| OGTT | 口服葡萄糖耐量试验，按规定时间采血，观察葡萄糖负荷后的血糖变化；本文记录的是 75 g 试验。 |
| 羊水池深度／AFI | 前者是一个液性暗区的深度；AFI 是羊水指数，来自四象限测量的合计，不能直接连成同一条趋势线。 |
| 臀位 | 指臀部或足部朝下的胎位；头位则是头部朝下。它描述当次姿势，不自动决定分娩方式。 |
| w／d | 图表横轴中的周和天。例如 20w6d 表示 20 周 6 天；Day 0 则只是该图选定的相对时间起点。 |

## 早孕：Emma 的检查，Yoyo 的第一次显影

### Emma：一开始，有个问题还没有答案

最初的超声在宫内看到了孕囊和卵黄囊，旁边却还有一个性质未明的结构。报告上的位置在宫角附近，建议密切随访、排除输卵管来源。

于是，那时的问题都围着这件事转：“现在住院观察，还是几天后再复查？”“如果真的是宫内、宫外同时妊娠，要做什么手术？”还问过，它们是不是同一时间受孕的。

但那个可疑结构，当时并没有被确认是另一个胚胎。不能因为曾经担心过复合妊娠，就把它写成已经发生的诊断。后来的留存记录里，也没有相关手术或最终确诊的经过。

接下来的几次复查，宫角、子宫壁和附件附近的结构仍是关注点。再往后，报告更多提到多发肌瘤及部分变性可能。描述慢慢变了，但不能把不同位置、不同切面量到的结节，直接当成同一个东西的连续变化。

那段时间，Emma 还做了几次抽血检查。五次 HCG（人绒毛膜促性腺激素）记录，从 **8,988** 到 **67,225 mIU/mL**。HCG 是一种妊娠相关激素，数值上升并不能回答宫角附近的结构是什么；这个问题，仍要交给超声随访和医生判断。

同阶段还留下孕酮 **116.25 nmol/L**、雌二醇 **3353 pmol/L** 的记录。对于当时的我们，这些都是新名词。现在把它们放回这段经过里，保留当时看到的数值，不用它们倒推一个“一切都没问题”的答案。

### Yoyo：第一次记录到心管搏动

Yoyo，后来有一份报告，第一次明确写下了你的胚芽头臀长 **2 mm**，以及“原始心管搏动（+）”。在那之前，记录里是孕囊和卵黄囊；从这一次开始，多了被超声记录到的搏动。

头臀长（CRL）是头顶部到臀部的距离。“（+）”表示当次看到了搏动，还不是一次完整的心脏结构检查。后来的记录依次是 **5 mm、8 mm、32 mm、65 mm**。把它们连起来，能看到几次检查之间的变化；空白的日子，仍然是空白，不假装每天都量过。

## 走过早孕：Emma 的子宫随访，Yoyo 的第一轮筛查

### Emma：子宫在变化，肌瘤也需要继续看

在最初和后续约 10 周阶段的报告中，子宫三径分别记录为 **58×54×45 mm** 和 **84×82×61 mm**。这是孕期子宫形态、大小变化留下的两次记录，但检查切面和多发结节都会影响测量，不据此推算精确的体积增长。

子宫肌瘤通常指子宫内或周围的非癌性增生，不过本文讨论的具体结构仍以报告和临床判断为准，不能仅凭这个通用定义替它们定性。肌瘤相关描述一直没有从随访里消失：早期出现过“多发肌瘤可能、部分变性可能”；后续约 23 周的结构筛查，又记录了宫底及左侧的肌瘤样结节。即使某次常规报告没有再测量，也不代表它们消失了。

| 记录阶段 | Emma 的相关影像记录 | 不能由此推断的事 |
| --- | --- | --- |
| 早孕随访中 | 左前壁混合结构 23×21×18 mm，仍有来源待辨的问题 | 不能直接当作已确诊的肌瘤或异位妊娠 |
| 同阶段另一个宫底结构 | 56×36×25 mm，内部见数个无回声区 | 没有病灶对应编号，不能说是之前某个结节快速长大 |
| 约 23 周随访 | 宫底 44×44×27 mm，另一个 31×29×25 mm；左侧 32×21×19 mm | 不做逐颗肌瘤的增长率比较，不据此决定手术 |

当时还问过：“肌瘤是不是变大了？”“会不会要切肌瘤？”这些问题说的都是 Emma 自己的身体。结节的大小、位置和性质需要随访，但尺寸本身不能告诉我们她疼不疼、有没有影响活动，更不能直接决定是否手术。

约 13 周检查还记录了双侧子宫动脉舒张早期切迹：右侧 PI **1.75**、RI **0.76**，左侧 PI **1.35**、RI **0.69**。这是一项需要放回产检背景理解的血流记录，不等于高血压或子痫前期诊断。资料缺少连续血压、尿蛋白和相关风险评估，不作进一步判断。

### Yoyo：NT、无创筛查与结构筛查

随着孕周往前走，报告里又出现 NT、无创筛查和结构筛查。每多一个名字，就多一个想弄明白的问题。它们看的是不同方面，不能拿其中一项替代所有检查。

| 阶段 | 资料中留下的记录 | 需要保留的边界 |
| --- | --- | --- |
| 约 13 周，NT 检查 | NT 1.8 mm；CRL 65 mm；记录胎心、胎动 | 单次超声不能排除所有染色体或结构问题 |
| 约 17 周，无创产前筛查 | 13、18、21 三体均为低风险 | 低风险属于筛查结果，不等于诊断或零风险 |
| 约 23 周，中孕结构筛查 | 转录内容列出了多项胎儿结构，未转录出明确重大结构异常的提示 | 不把“未报告异常”写成“全部问题均已排除” |
| 约 26 周，常规超声 | 记录胎心、胎动，胎位为臀位；羊水指数 9.7 cm | 这是当次检查的记录，不据此预判分娩方式 |

**NT 是什么？** 它指早孕超声测量的胎儿颈后透明层，与颈后的一层液体有关。它是筛查信息的一部分，不是仅凭一个厚度就作出诊断。资料记录 Yoyo 的 NT 为 **1.8 mm**，这里只保留数值，不把它延伸成对所有疾病的排除。

{{< pregnancy-diagram "nt" >}}

这张教材图里，箭头指向颈后的液体间隙，帮助理解 NT 测量的大致位置。它不是 Yoyo 的影像，也不是让我们照着图自行测量。

无创产前筛查（NIPT）是通过抽血评估部分染色体异常风险的筛查，并非取出 Yoyo 的组织进行确诊。这里的“三体”是指对应编号的染色体多了一份；本次记录为 13、18、21 三体均低风险。约 23 周的结构筛查则列出了多项结构，还留下侧脑室宽度 **5.7 mm**、小脑横径 **24 mm**、小脑延髓池宽度 **6.7 mm**、肱骨长 **37 mm** 等测量。这里不把“看见了某个结构”扩大成“相关问题已经全部排除”。

## 中孕：Emma 的身体指标，Yoyo 的生长记录

### Emma：宫颈长度与日常状态

宫颈是子宫下端连接阴道的部分。这里的“宫颈长度”是超声测量值，“内口”指它朝向子宫腔的一端。两次经阴道超声中，宫颈长度从 **42 mm** 记录到 **35 mm**，两次均写了内口闭合。它们是不同检查时的测量，不代表宫颈每天都按同样速度变短，也不能据此诊断宫颈机能不全。

{{< pregnancy-chart "cervix" >}}

这两次检查除了看 Yoyo，也看了 Emma 的宫颈。曲线连起的是两个测量时点，不是她每天身体变化的速度；要不要调整活动或进一步检查，不能只凭线条往下走就决定。

Emma，关于你自己的感受，我想留一点位置给你来写：那段时间吃饭、睡觉和活动有没有变化，哪些时候不舒服，哪些事情让你轻松些。报告没有替你回答这些，我们也不从 Yoyo 的测量值里猜。

### Emma：一次糖耐量检查留下的记录

OGTT 是口服葡萄糖耐量试验：按照检查要求服用葡萄糖，并在规定时间采血，观察血糖变化。孕中期的这次 75 g OGTT 留下了三个数值：空腹 **4.13 mmol/L**，服糖后 1 小时 **6.74 mmol/L**，2 小时 **5.49 mmol/L**。

按资料中列出的对应诊断界值 **5.1、10.0、8.5 mmol/L**，三项均未达到界值。这里仅描述这一次检查的数值对照，不据此评价全部代谢状况，也不自行调整饮食或后续检查安排。
